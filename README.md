# 截蛇大亂鬥

培養皿貪食蛇網頁遊戲（slither 風格）。你一出世係條幼線，成個培養皿都係會發光嘅養份，食得越多越長。同場有 29 條大細唔同嘅電腦蛇，只要佢哋個頭撞落你條身，成條就會散開變成一粒粒養份，任你食。

- 網址（開咗 GitHub Pages 之後）：https://fiveathree.github.io/snake/
- 整個遊戲就係一個 `index.html`，唔使安裝、唔使建置，直接用瀏覽器打開都玩得。

## 玩法

| | 電腦 | 手機 |
|---|---|---|
| 方向 | 滑鼠指去邊就行去邊，或者用 ← → | 手指喺畫面拖去想去嘅方向 |
| 加速 | 撳住 空白鍵 / Shift / W / ↑ / 滑鼠左鍵 | 撳住右下角「衝」掣 |

### 規則

- 條蛇會自己一直向前行。
- 食養份會變長變粗。大粒養份值多啲，死蛇散出嚟嘅養份最大粒。
- 加速冇代價：唔會燒短條身，亦唔會甩養份，撳住幾耐都得。
- **你個頭**撞落其他蛇條身，或者撞出培養皿邊界，就輸。
- 其他蛇個頭撞落**你條身**，佢就會散晒做養份，算你截斷一條。
- 啱啱出世頭 1.5 秒會閃，期間唔會死。

## 畫面

- **左上：** 你嘅長度同截斷數。
- **右上：** 排行榜前 6 名；你唔喺頭 6 名都會顯示你嘅名次。
- **左下：** 小地圖。橙點係你，金點係最長嗰條，灰點係其他蛇。
- **最長嘅蛇：** 頭上有金色皇冠同名。佢唔喺畫面入面時，畫面邊會有金色箭嘴指住佢嘅方向。
- **底部：** 半透明加速提示，玩緊先會顯示。
- **結束畫面：** 最後長度、今局最長、截斷數、歷來最佳（記喺瀏覽器入面）。

## 遊戲設定

想改難度或者場地大細，改 `index.html` 入面 `<script>` 開頭嗰行就得：

```js
const TAU=Math.PI*2,R=3900,NAT=4500,BOTS=29,CELL=80;
```

| 設定 | 意思 | 而家數值 |
|---|---|---|
| `R` | 培養皿半徑 | 3900 |
| `NAT` | 場上自然養份數量 | 4500 |
| `BOTS` | 電腦蛇數量（連你 = 30 人場） | 29 |

其他重點：

- 長度公式 `segN`：每粒養份令條蛇長大約 8 像素，大蛇會慢慢放緩。
- 速度：正常 2.7、加速 5.6（每格畫面行幾多像素）。
- 新養份一半隨機灑落成個場，一半喺你附近但喺畫面以外出現；你周圍養份太少會自動補一批。
- 死蛇散出嚟嘅養份大約 45 秒後慢慢消失。

## 電腦蛇 AI

- 會避開前面其他蛇條身同邊界。每條蛇反應唔同，有啲笨啲，會撞落你條身。
- 進取型電腦蛇見到附近有細過佢嘅蛇（包括你），會衝去你前面想截你。
- 冇危險嘅時候會揀附近最抵食嘅養份去食。
- 死咗大約 3 至 4 秒後會喺遠離你嘅地方重生。

## 發佈（GitHub Pages）

1. 去 https://github.com/fiveathree/snake ，用 fiveathree 帳號登入。
2. 撳 repo 頂部嘅 **Settings**。
3. 左邊欄 **Code and automation** 下面撳 **Pages**。
4. **Build and deployment** → **Source** 揀 **Deploy from a branch**。
5. **Branch** 揀 `main`，資料夾揀 `/ (root)`，撳 **Save**。
6. 等一至兩分鐘，頁面會顯示 **Your site is live at…**。

每次 push 新版本，等一至兩分鐘後撳 **Ctrl + Shift + R**（Mac：**Cmd + Shift + R**）強制重新載入就見到更新。

## 技術

- 純 HTML + Canvas 2D + JavaScript，冇用任何框架。
- 字型：Google Fonts 嘅 Noto Sans TC 同 Chakra Petch。
- 養份同蛇身用預先畫好嘅小圖貼上去，加上空間網格做碰撞同進食判斷，30 條蛇同場都可以跑到每秒 60 格。
- 最佳紀錄存喺瀏覽器 `localStorage`，只喺同一部機同一個瀏覽器有效。

## 更新紀錄
